Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Sample data

On first run, the app seeds a few example escrows so you can explore the UI immediately. These are stored in your browser's localStorage under the key `escrows:v1` and will persist across reloads.

- To clear: open DevTools > Application > Local Storage and delete the `escrows:v1` key, or run `localStorage.removeItem('escrows:v1')` in the console.
- To disable seeding: pre-populate `escrows:v1` with an empty array `[]` in localStorage before loading the app, or replace the contents of `app/data/sampleEscrows.ts` with an empty list.
You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
